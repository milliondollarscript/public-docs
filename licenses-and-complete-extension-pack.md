# Licenses And The Complete Extension Pack

The Complete Extension Pack provides one license for the premium extensions currently included in the pack. Monthly, yearly, and lifetime plans include the same extensions, updates, licensed documentation, and support. The difference is how long access remains active.

## Compare Plans

| Plan | Billing | Access |
|---|---|---|
| Monthly | Recurs monthly | Continues while the subscription is active |
| Yearly | Recurs yearly | Continues while the subscription is active |
| Lifetime | One payment of CAD 500 | Does not expire |

Each plan supports up to five active site installations. A plan does not reserve a fixed snapshot of the pack: extensions added to the current pack membership become available to active monthly and yearly customers and to valid lifetime customers without another purchase.

The pack works with compatible Million Dollar Script 2 and Million Dollar Script 3.0 packages. The update service selects the package for the requesting Million Dollar Script generation; it does not install a Million Dollar Script 3.0 extension on a Million Dollar Script 2 site or the reverse.

## Activate And Move A Site

Enter the pack license key when Million Dollar Script asks for extension access. An activation uses one of the five site slots. Deactivate a site before moving the license to another installation so the slot becomes available again.

Use the customer portal to review the plan, active installations, downloads, and licensed guides. Lifetime licenses show **Lifetime**, do not expire, and have no subscription cancellation or renewal controls.

## Cancellations, Refunds, And Access

Canceling a monthly or yearly subscription turns off automatic renewal. Access continues through the paid billing period shown in the portal, then licensed downloads, updates, private documentation, and support stop.

A refunded or revoked purchase no longer authorizes new downloads, updates, or private documentation. It does not remotely remove extension files already installed on a WordPress site. Keep a current backup before changing plans, licenses, or installed extensions.

## Add Or Update Pack Extensions

Open **Million Dollar Script > Extensions** to view packages compatible with the current site. WordPress update checks use the same license and compatibility rules. If an expected package or update is missing:

1. Confirm that the pack license is active for this site.
2. Confirm that an activation slot is available.
3. Refresh the WordPress Updates screen or run **Check again**.
4. Refresh remote documentation from **Million Dollar Script > Documentation** if licensed guides remain stale.
5. Review [Troubleshooting](/docs/mds-3/million-dollar-script/3.0.0/main/troubleshooting#plugin-updates) before contacting support.

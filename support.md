## Before Contacting Support

Record:

- Million Dollar Script version and distribution.
- WordPress, PHP, database, and WooCommerce versions.
- Active MDS extensions and their versions.
- The affected grid and order IDs, without sharing customer secrets.
- Exact steps to reproduce the problem.
- Relevant browser-console, network, PHP, and scheduled-action errors.
- Whether the problem remains with a default theme and unrelated plugins disabled on a staging copy.

Remove API keys, license keys, tester access keys, order keys, manage tokens, passwords, email addresses, and other personal information before posting logs publicly.

## Support Channels

Use the [support page](/support) for account or private support. Use GitHub Issues for reproducible software defects and GitHub Discussions or the community channel for implementation questions. Do not post credentials or customer data in a public issue.

Paid-extension documentation and support are available only while the corresponding license or support entitlement is active. Public core and free-extension documentation remains available without a paid license.

## Versioned Help

Use the documentation version selector before following a guide. MDS 2 and MDS 3.0 have different storage, menu, API, block, and extension architectures. Existing MDS 2 sites can continue using the [MDS 2 documentation](/docs/mds-2); new development should use MDS 3.0.

## Security Reports

Do not disclose a suspected vulnerability in a public issue before it is reviewed. Use the private contact route on the support page, include the affected version and a minimal reproduction, and avoid accessing data that is not yours.
